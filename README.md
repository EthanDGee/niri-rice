# niri-rice

A personal rice of my arch system using niri+noctalia alongside some tool configs

## Niri

My personal [niri](https://github.com/niri-wm/niri) config. This section lists only what differs from the official starter config (`default-config.kdl`). Config lives in `niri/` and is split across three files.

### Config Layout

- **`config.kdl`**: Main config, hand-edited. Includes the other two files.
- **`monitor.kdl`**: Stores monitor data, generated by `nwg-displays`. Included at the top of `config.kdl`.
- **Theme colors file**: The color scheme is generated and applied by Noctalia (see [Coloring](#coloring)).

### Input

- **Warp mouse to focus**: The cursor jumps to the center of newly focused windows.
- **Focus follows mouse**: Moving the mouse into a window focuses it.

### Layout

- **Transparent background**
- **Focus ring**: Thinner at 2.5px (stock is 4px).
- **Shadows**: Drop shadows behind windows. Softness is 15, spread is 7, offset is `x=0 y=5`, and the color is `#0007`.
- **Client-side decorations**: `prefer-no-csd` is on, so applications drop their own title bars and niri draws the ring around them.

### Window Rules

- **Rounded corners**: All windows get `geometry-corner-radius 11.5` with `clip-to-geometry`. `draw-border-with-background` is off so the ring does not show through semitransparent windows.
- **Shell settings window**: Matched by app-id, opens floating at 1080x920.

### Keybinds

`Mod` is `Super` on a TTY session.

#### Shell

- **`Mod+Ctrl+Return`**: Toggle the launcher. Replaces `Mod+D` (`fuzzel`).
- **`Mod+S`**: Toggle the control center.
- **`Mod+Comma`**: Toggle the shell settings. Replaces stock `consume-window-into-column`, and `expel-window-from-column` on `Mod+Period` is commented out.
- **`Alt+Tab`**: Window switcher.
- **`Mod+V`**: Toggle the clipboard history panel.
- **Volume and brightness keys**: Sent to the shell instead of `wpctl` and `brightnessctl`, so the on-screen display shows.

#### Applications

- **`Mod+Return`**: Ghostty.
- **`Mod+E`**: Dolphin.
- **`Mod+B`**: Brave Origin.
- **`Mod+Shift+B`**: Helium Browser.

#### Navigation

- **Vertical focus**: `Mod+Up`/`Mod+Down` and `Mod+K`/`Mod+J` use `focus-window-or-workspace-up`/`down`. They move through the windows in a column, then continue to the workspace above or below at the first or last window.
- **Move binds use `Shift` instead of `Ctrl`**: This covers moving windows and columns, column to first or last, and column to workspace (`Mod+Shift+1` to `9`).
- **Move window up or down**: `Mod+Shift+Up`/`Down` and `Mod+Shift+K`/`J` use `move-window-up-or-to-workspace-up`/`down`, so a window at the edge of its column moves to the next workspace.
- **Monitors**: `Mod+Ctrl` plus a direction focuses another monitor. `Mod+Shift+Ctrl` plus a direction moves the column to it. Stock puts focus on `Mod+Shift`.
- **Workspace reordering**: `Mod+Shift+U`/`I` and `Mod+Shift+Page_Down`/`Page_Up`.

#### Window Management

- **`Mod+M`**: Maximize the column. Swapped with stock, where `Mod+F` does this.
- **`Mod+F`**: Maximize the window to the screen edges. Swapped with stock, where `Mod+M` does this.
- **`Mod+T`**: Toggle floating for the window. Moved from stock `Mod+V`.
- **`Mod+Shift+T`**: Switch focus between floating and tiling. Moved from stock `Mod+Shift+V`.
- **`Mod+Ctrl+Shift+E`**: Quit niri. Moved from stock `Mod+Shift+E`. The confirmation dialog stays.

## Noctalia

My [Noctalia](https://github.com/noctalia-dev/noctalia-shell) shell config back up.

### General Settings

- **Location**: Auto-detected, which is used used the weather widget.
- **Screen time**: Time tracking is enabled.
- **Notifications**: Scaled down to 0.75 with 0.8 background opacity.
- **Idle**: Three behaviors are defined but all disabled: lock after 5 minutes, screen off after 11 minutes, and lock plus suspend after 15 minutes.

### Bar

- **Behavior**: Auto-hides, and `reserve_space` is off so windows are not pushed down when it shows.
- **Look**: 61px thick at 1.5 scale, 0.5 background opacity, 30px end margins, and a contact shadow.
- **Capsules**: Related widgets share one capsule that expands as an accordion toward the end of the bar.

#### Left

Launcher, topgrade, clipboard, and two accordion groups.

- **Plugins**:  wallhaven, ambient sounds, emoji selector, calculator, keybind cheatsheet, default application setter,  and OCR.
- **Long Term Use**: Nightlight and caffeine.

#### Center

Clock, weather, GitHub, and the control center. All are scaled down to 90%.

#### Right

Notifications, the session menu, two accordion groups, then power.

- **Power**: Battery and power profile.
- **General Settings**: Network, volume, input volume, brightness, bluetooth.

### Lock Screen

- **Background**: Blur at 0.25 with a 500ms transition.
- **Login box**: A single `login_box` widget on `eDP-1`, 810x196 with 0.88 opacity and rounded corners. It shows weather, media, caps lock state, keyboard layout, and session buttons.

### Theme

- **Theme**: The built-in `Tokyo-Night` scheme.
- **Wallpaper**: Set using [wallhaven] in combination with the wallhaven plugin
- **Application Theming**: Themes are automatically applied to `btop`, `gtk3`, `gtk4`, `kcolorscheme`, `kitty`, `niri`, `qt`, and `lazygit`.

### Plugins

All eight plugins are enabled, with `auto_update` set to `none` so versions only change when I update them by hand. Plugins with a niri keybind note it below.

- **[wallhaven](https://github.com/noctalia-dev/official-plugins/tree/main/wallhaven)**: Sets wall paper using wall papers from wall haven.
- **[ocr](https://github.com/Fel-2/community-plugins/tree/main/ocr)**: Uses OCR to extract text from screen selection and copies it to clipboard. Uses  `Mod+Shift+S`.
- **[keybind-cheatsheet](https://github.com/noctalia-dev/community-plugins/tree/main/keybind-cheatsheet)**: A searchable panel of active shortcuts. Opened by `Mod+Shift+Slash`
- **[github-kanban](https://github.com/noctalia-dev/community-plugins/tree/main/github-kanban)**: GitHub dashboard covering notifications, pull requests, issues, repositories, and recent Actions runs.
- **[ambient-sounds](https://github.com/noctalia-dev/community-plugins/tree/main/ambient-sounds)**: A background player for white noise.
- **[emoji-picker](https://github.com/noctalia-dev/community-plugins/tree/main/emoji-picker)**: search pop up for emoji and symbols. Uses  `Mod+Shift+E`
- **[topgrade-wrapper](https://github.com/nightwatch75/community-plugins/tree/main/topgrade-wrapper)**: Shows pending/installs updates from many sources (e.g, tmux, aur, nvim)
- **[default-apps](https://github.com/noctalia-dev/community-plugins/tree/main/default-apps)**: View and change default applications.
- **[calculator](https://github.com/noctalia-dev/community-plugins/tree/main/calculator)**: simple calculator widget. Uses `Mode+Shift+C`

### Niri Keybinds

The shell binds in `niri/config.kdl` call `noctalia msg`:

- **`Mod+Ctrl+Return`**: Toggle the application launcher.
- **`Mod+S`**: Toggle control center.
- **`Mod+Comma`**: Toggle settings.
- **`Alt+Tab`**: Open window switcher.
- **`Mod+V`**: Toggle the clipboard history panel.

#### Plugins

These binds call shell plugins.

- **`Mod+Shift+S`**: Extract text from a screenshot region (OCR).
- **`Mod+Shift+Slash`**: Searchable list of keybinds. Replaces the stock hotkey overlay bind.
- **`Mod+Shift+E`**: Emoji picker.

#### Mouse Wheel

- **`Mod+Wheel` up/down**: Focus the workspace above or below.
- **`Mod+Shift+Wheel` up/down**: Move the workspace up or down. Stock moves the column to another workspace on `Mod+Ctrl+Wheel`.
- **`Mod+Wheel` left/right**: Focus the column left or right.
- **`Mod+Shift+Wheel` left/right**: Move the column left or right.

#### Touchpad

- **`Mod+Touchpad` scroll down/up**: Open or close the overview with `open-overview` and `close-overview`.
