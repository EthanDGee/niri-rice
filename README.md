# niri-rice

A personal rice of my arch system using niri+noctalia alongside some tool configs

## Niri

My personal [niri](https://github.com/niri-wm/niri) config. This section lists only what differs from the official starter config (`default-config.kdl`). Config lives in `niri/` and is split across three files.

### Config Layout

- **`config.kdl`**: Main config, hand-edited. Includes the other two files.
- **`monitor.kdl`**: Stores monitor data, generated by `nwg-displays`. Included at the top of `config.kdl`.
- **Theme colors file**: Included at the bottom of `config.kdl`.

### Input

- **Warp mouse to focus**: The cursor jumps to the center of newly focused windows.
- **Focus follows mouse**: Moving the mouse into a window focuses it.

### Layout

- **Transparent background**
- **Focus ring**: Thinner at 2.5px (stock is 4px).
- **Shadows**: Drop shadows behind windows. Softness is 15, spread is 7, offset is `x=0 y=5`, and the color is `#0007`.
- **Client-side decorations**: `prefer-no-csd` is on, so applications drop their own title bars and niri draws the ring around them.

### Window Rules

- **Rounded corners**: All windows get `geometry-corner-radius 11.5` with `clip-to-geometry`. `draw-border-with-background` is off so the ring does not show through semitransparent windows.
- **Shell settings window**: Matched by app-id, opens floating at 1080x920.

### Keybinds

`Mod` is `Super` on a TTY session.

#### Shell

- **`Mod+Ctrl+Return`**: Toggle the launcher. Replaces `Mod+D` (`fuzzel`).
- **`Mod+S`**: Toggle the control center.
- **`Mod+Comma`**: Toggle the shell settings. Replaces stock `consume-window-into-column`, and `expel-window-from-column` on `Mod+Period` is commented out.
- **`Alt+Tab`**: Window switcher.
- **Volume and brightness keys**: Sent to the shell instead of `wpctl` and `brightnessctl`, so the on-screen display shows.

#### Applications

- **`Mod+Return`**: Ghostty.
- **`Mod+E`**: Dolphin.
- **`Mod+B`**: Brave Origin.
- **`Mod+Shift+B`**: Helium Browser.

#### Navigation

- **Vertical focus**: `Mod+Up`/`Mod+Down` and `Mod+K`/`Mod+J` use `focus-window-or-workspace-up`/`down`. They move through the windows in a column, then continue to the workspace above or below at the first or last window.
- **Move binds use `Shift` instead of `Ctrl`**: This covers moving windows and columns, column to first or last, and column to workspace (`Mod+Shift+1` to `9`).
- **Move window up or down**: `Mod+Shift+Up`/`Down` and `Mod+Shift+K`/`J` use `move-window-up-or-to-workspace-up`/`down`, so a window at the edge of its column moves to the next workspace.
- **Monitors**: `Mod+Ctrl` plus a direction focuses another monitor. `Mod+Shift+Ctrl` plus a direction moves the column to it. Stock puts focus on `Mod+Shift`.
- **Workspace reordering**: `Mod+Shift+U`/`I` and `Mod+Shift+Page_Down`/`Page_Up`.

#### Window Management

- **`Mod+M`**: Maximize the column. Swapped with stock, where `Mod+F` does this.
- **`Mod+F`**: Maximize the window to the screen edges. Swapped with stock, where `Mod+M` does this.
- **`Mod+T`**: Toggle floating for the window. Moved from stock `Mod+V`.
- **`Mod+Shift+T`**: Switch focus between floating and tiling. Moved from stock `Mod+Shift+V`.
- **`Mod+Ctrl+Shift+E`**: Quit niri. Moved from stock `Mod+Shift+E`. The confirmation dialog stays.

#### Plugins

These binds call shell plugins.

- **`Mod+Shift+S`**: Extract text from a screenshot region (OCR).
- **`Mod+Shift+Slash`**: Searchable list of keybinds. Replaces the stock hotkey overlay bind.
- **`Mod+Shift+E`**: Emoji picker.

#### Mouse Wheel

- **`Mod+Wheel` up/down**: Focus the workspace above or below.
- **`Mod+Shift+Wheel` up/down**: Move the workspace up or down. Stock moves the column to another workspace on `Mod+Ctrl+Wheel`.
- **`Mod+Wheel` left/right**: Focus the column left or right.
- **`Mod+Shift+Wheel` left/right**: Move the column left or right.

#### Touchpad

- **`Mod+Touchpad` scroll down/up**: Open or close the overview with `open-overview` and `close-overview`.

#### Removed Keybinds
